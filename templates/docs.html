Getting Started

1. Create an Account

Navigate to the registration page and create your account. Free accounts get 3 AI prompts per day. For unlimited access, upgrade to Pro for 1,200 BDT/month via bKash.

2. Upload a Project

Drag and drop your project archive (zip, rar, tar, 7z) into the upload zone in the AI Agent panel. The agent will automatically extract and analyze the project structure, creating a detailed context map of all files and their relationships.

3. Describe Your Task

Type your task in the input area. Be specific about what you want the agent to do. Examples:

  • Fix the login bug in auth.py - users can't login with correct password
  • Add user authentication with JWT to the Flask API
  • Refactor the database layer to use SQLAlchemy ORM
  • Add unit tests for all API endpoints
  • Convert this JavaScript project to TypeScript

4. Watch the Agent Work

Click "Start Agent" and watch in real-time as the AI thinks, plans, and executes. The activity feed shows everything the agent is doing - its reasoning, the files it's editing, commands it's running, and verification results.

AI Agent Modes

Autonomous Mode (Auto)

Like Devin - the agent works independently. It analyzes the project, creates a plan, executes each step, and verifies its work. You can watch the real-time activity feed and intervene via chat if needed.

Assisted Mode

The agent suggests actions but waits for your approval before executing. Good for when you want more control over what changes are made to your codebase.

Context Window

Context Limit: YubiLab's AI agent has a context window of 8,100 tokens. If your project exceeds this limit, the agent automatically processes it part by part, ensuring 100% coverage of your codebase.

The agent tracks which parts of the codebase it has already processed and which remain. It builds a cumulative understanding of the project across all parts, so even large codebases get thorough analysis.

Keyboard Shortcuts

  • Ctrl+S - Save current file

  • Enter - Execute terminal command

API Endpoints

Authentication

POST /api/auth/register  - Register new user
POST /api/auth/login     - Login
GET  /api/auth/me        - Get current user

AI Agent

POST /api/agent/sessions              - Create session
POST /api/agent/sessions/:id/chat     - Chat with agent
GET  /api/agent/sessions/:id/activity - Get activity log

AI Chat

POST /api/ai/chat - Direct AI chat (no agent)

Terminal

POST /api/terminal/sessions            - Create terminal
POST /api/terminal/sessions/:id/execute - Run command
